1 Introduction

A looped (recurrent-depth) language model applies a shared stack of layers several times per token Dehghani et al. (2018); Geiping et al. (2025); Zhu et al. (2025). Inference engines for these models keep one KV plane per loop so that a token at depth d attends to the depth-d keys and values of earlier tokens Schwethelm et al. (2026); with early exit, a token that stops at depth e<R copies its depth-e entries into the deeper planes or the engine reads them through an alias Mishra et al. (2026). Either way the cache holds R planes per token. For Ouro-1.4B in BF16 that is 768 KiB per token, and a decode step reads about 10.1 GB of weights, so KV reads overtake weight reads once the resident context exceeds about 12.8k tokens across a batch.

Prior work reduces this cache with residual coding against the final loop’s plane Kim et al. (2026), cross-loop latent compression Neill & Reid (2026), sparse late-loop updates Yang & Liu (2026) and general KV quantizers Liu et al. (2024); Hooper et al. (2024); Ashkboos et al. (2024). To choose among them, one needs to know which planes and which of keys and values carry the error, whether a cheap sensitivity estimate ranks formats correctly, and whether reusing one quantized weight R times compounds its error. The measurements below examine these questions on identical rows. Figure 1 summarizes the main outcome: sensitivity and realized error favor different cache components, typical sequences follow the local second-order map, and lower one-step KL does not guarantee task accuracy. Criteria and input tables were frozen before each GPU job; many predictions failed, and Section 7 records the verdicts.

Contributions.

  • A row-matched protocol for comparing measured KL, local second-order prediction and diagonal Fisher on the same cache perturbations, together with a sensitivity map of the multi-plane cache (Sections 2 and 3).
  • Evidence that second-order prediction works for typical sequences but fails on a small number of confident rows, and a localization of that failure to early layers (Section 4).
  • Tests of seven statistical and dynamical predictions on held-out chains, a second distribution and a second model (Sections 5 and 6).
  • A cell-level allocation study linking Ouro-1.4B’s Fisher failure to a 2-bit key cell post hoc, with mixed task results. Both allocator families protect the second Ouro checkpoint’s outlier, where measured costs lose to Fisher (Section 8).

Scope. Allocation uses dense planes and quantization simulated in FP32. A separate batch-one L40S pilot times a physical packed reader, but its full-model numerical gate fails; quality-qualified serving performance and long-context capacity remain unestablished. Task accuracy concerns Ouro-1.4B; Huginn supplies KV and shared-weight diagnostics, and Ouro-2.6B adds a teacher-forced checkpoint test. Cache-design relevance is indirect.

2 Three predictors on identical rows

Model and cache. Ouro-1.4B has 24 layers executed R=4 times; every loop ends with a normalization whose output feeds the next loop and the exit gate Zhu et al. (2025). The cache stores, for every token, layer and loop, one key and one value vector per KV head. We write X for the stored planes and index a plane by its loop ℓ∈{1,…,R}. Huginn-0125 runs a prelude of 2 layers once, a core of 4 layers R=32 times from a random initial state, and a coda of 2 layers Geiping et al. (2025); we quantize its core planes and replace the random state by a deterministic draw seeded by the token ids. This changes the model’s default inference behavior, so the Huginn results describe this deterministic variant.

Protocol. We teacher-force fixed greedy chains. For every scored row t the model runs all R loops, reads strict-prefix keys and values from the stored planes, and uses its freshly computed key and value on the diagonal, exactly as a decode step does. A storage format maps the planes to X+Δ; the row distribution changes from pt=softmax⁡(zt​(X)) to qt, and we report ∑tKL(pt∥qt). Arithmetic is the inference engine’s layer code in FP32 with TF32 disabled; only the paged cache is replaced by dense planes.

Registration and devices. For each batch, the analysis code and criteria entered a frozen input table before the run; the job checked that table, ran CPU self-tests and archived the outputs with checksums (supplementary Appendix B). The registered analysis batches used single GH200 GPUs except the twentieth registration (RTX PRO 6000), where a uniform INT4 control reproduced the GH200 per-chain KL (aggregate ratio 1.0002). The separate L40S follow-ups appear in Appendices O and P. Earlier H100 results and analyses added after a run are marked as such. The batches were run sequentially. Some later criteria therefore use earlier outcomes; we identify those analyses as confirmations rather than prospective tests. Here “registered” means that the criteria were written to a frozen file before the corresponding run and checked against its outputs; it is an audit trail, not a guarantee against post hoc choices, which we label where they occur.

Statistics. Confidence intervals for the shared-weight results are batch bootstraps (Tables 5 and 6). Answer-change counts in free generation are sign tests on discordant problems, one-sided where the registration specifies it. We report these p-values descriptively. The registered batches are not corrected for multiplicity across criteria, and we do not treat any single p-value as the main evidence. GSM8K uses the registered strict-match rule. A post hoc audit reuses the saved task’s flexible-extract rule, which selects the last numeric match; it tests format sensitivity, not mathematical correctness. Direct format comparisons and changes in those differences use paired per-problem intervals (supplementary Appendix K). These intervals condition on the tested checkpoint, prompts and allocated format; they do not propagate uncertainty from selecting or resampling the calibration chains and recomputing the allocation.

3 Values carry the sensitivity, keys carry the error

On 64 GSM8K chains (6,658 scored rows), values carry 94% of the diagonal Fisher mass of the stored cache and the final loop’s value plane alone 64% (Table 1). Measured KL splits the other way: quantizing only keys or only values with direct INT4 attributes 89% of the KL to keys (94% for FP8), and the final plane contributes 69%. The diagonal prediction attributes 88.8% to keys, so the reversal comes from error sizes, not from a failure of the map: per element, the keys’ quantization error is much larger. For the 15 formats measured in both studies, the GH200 KL divided by the earlier H100 value lies in 0.92–1.01.

4 Second order is right for typical sequences, not in aggregate

Registered outcome. The aggregate measured/JVP ratio falls in [0.8,1.25] for only 7 of 21 formats, and the log–log slope of measured KL on the diagonal prediction is 1.24 (Table 2; criteria in Table S2). Additivity of plane and K/V subsets, the rounding-temperature test and the numerical floors pass. For formats in the linear band, KL scales as ϵ2 under Δ→ϵ​Δ.

Typical sequences. The aggregate is dominated by a few sequences. The median per-sequence ratio lies in [0.8,1.25] for 19 of 21 formats (Fig. 2). The second batch made this a registered criterion and tested it on 136 chains not used here: 24 of 24 medians fall in the band, and 21 of 24 on MATH-500.

Why the aggregate fails (post hoc). On the sequence with the largest discrepancy for d4h-all, the JVP predicts 11.5 times the measured KL, and it is the correct small-perturbation limit: KL⁡(ϵ)/ϵ2 approaches it only for perturbations far below the quantization error (Fig. 3). One row carries 92.6% of the second-order term; there the model is confident (top probability 0.9998), and linearizing the network while keeping the softmax exact makes the prediction worse, so the saturation is inside the network. A re-registered localization on 12 new sequences finds it in a few layers of the first two loops: in all 19 scored cases loops 1 and 2 hold at least 99.8% of the excess (supplementary Appendix D).

These results support local second-order prediction on typical sequences of the tested formats. Aggregate ratios remain necessary to expose concentrated errors; reporting only medians would hide them. We therefore report both, because the linear radius differs between rows by orders of magnitude.

5 Tests of statistical and dynamical predictions

After the first batch we wrote down seven predictions, each with a source theory, a numerical prediction and a falsification condition, and tested them on 136 held-out GSM8K chains, 24 MATH-500 chains and Huginn (Table 3; full derivations and measurements in supplementary Appendix D).

What the statistical models get right. Per-group scaling sets the error by each group’s range, which grows like 2​ln⁡g for a Gaussian tail and like g1/α for a power-law tail. Measured KL follows the exact error ratios of both branches on both distributions: heavy-tailed without rotation (keys’ kurtosis 9.5), near-Gaussian after a Hadamard rotation (T2, Table 4). Round-to-nearest has mean square error 112 of a step squared and stochastic rounding 16; stochastic rounding measures 1.95 times round-to-nearest on Ouro and 1.68 on Huginn’s own chains (T3). The aggregate’s tail is heavy, but its index lies between 1 and 2, not below 1 (T1).

What the fixed-point picture gets wrong. Huginn is trained to approach a fixed point over its loops Bai et al. (2019), and its planes do converge (T4b). Adjacent converged planes should then receive nearly equal round-to-nearest errors whose cross terms add, so the diagonal prediction should underestimate it. It barely does (ratio 1.13, falsification threshold 1.2). A third registration separated the two reasons on Huginn’s own chains: the errors of adjacent late planes are strongly correlated (ρJ=0.87), but the output responds to adjacent planes along nearly orthogonal directions (alignment 0.13), so cross terms make up only 13.9% of the second-order term. On Huginn’s own chains one sequence switches on above the quantization scale; its excess sits in one row, one layer and a band of middle loops (supplementary Appendix E).

6 Shared-weight error accumulates through the middle loops

Ouro. At R=4, κ is 1.28–1.34 for all seven formats (Table 5): the four uses’ gradients are mildly correlated, and κ is a property of that geometry rather than of the format. The Fisher-free ratio agrees at 1.13–1.39 in or near the linear regime. The registered amplification hypothesis, that sharing makes linear response fail at a finer format at R=4 than at R=1, is not supported.

Huginn. The diagonal κ grows from 1.06 at R=4 to 2.68±0.21 at R=32 (32 Fisher draws, jackknife; Table 6), with formats within 1.6% and κ⁡(32)=2.43±0.14 on Huginn’s own chains; with 8 draws the second registration had overstated it as 3.66, and disjoint 8-draw subsets scatter as 2.04, 2.92, 2.46, 3.25. Fisher-weighted loop gradients correlate more at even than at odd loop distances (Fig. 4, post hoc). The local second-order ratio (Eq. 2) separates the formats that the diagonal Fisher averages together: κ2 is 4.09 for INT4 and 1.65 for INT8, where the diagonal values are 2.68 and 2.70. INT8 is linear, and its measured coherence KLall/∑ℓKLℓ=1.74 agrees. Synthetic error directions (stochastic rounding, group-mean bias, shrinkage) all give 2.21–2.44, and a chain’s κ2 is largely shared across directions (rank correlation 0.84 on 16 chains). That it rises with an expanding middle-loop map was registered and falsified.

Where the coherence sits. Because the JVP is a quadratic form in the coefficients aℓ of the tangent ∑ℓaℓ​Δ​Wℓ, JVPs of four loop blocks (1–8, 9–24, 25–28, 29–32), of their six pairwise unions and of the alternating signs (−1)ℓ split the cross term JVPall−∑ℓJVPℓ exactly: into within- and between-block parts, and into even- and odd-lag sums. On 16 chains the split closes to 2×10−6 of JVPall. For shrinkage the late loops carry most of the cross term only because they carry most of the single-loop mass: relative to equal correlation of all loop pairs they are under-correlated (0.75×), while pairs within loops 9–24 are 2.2× enriched. For INT4 the middle block also carries most of the chain-to-chain variation (0.53, against 0.29 for shrinkage). We registered these readings and tested them on two fresh samples of 12 chains each, the second frozen before the first was read (Table S9): the middle-block enrichment (2.63 and 3.07) and the direction dependence (INT4 0.55 and 0.45 against shrinkage 0.25 and 0.25) replicate. The share of variation carried by odd-lag cross terms, 0.87 on the original chains, is 0.43 and 0.52 on the new ones, and its link to the loop map’s spectrum does not replicate. Near the fixed point, loops neither add KV rounding errors coherently nor align their weight gradients, and pairs of middle loops are the most correlated (2.63–3.07× their equal-correlation share on the new samples).

8 Diagnostic formats and cache layout

Where to spend bits. The tenth and eleventh registrations turned the sensitivity map into a diagnostic allocator. Every (plane, K|V, layer) cell gets its own width from {2, 4, 8, 16} bits (rotated direct INT with per-group scales, or BF16). In the format byte model, each plane is read once and nominal bytes read per step equal bytes stored; the dense FP32 simulation does not realize those traffic savings. A greedy rule frozen before the job spends a budget on the upgrades with the largest cost reduction per stored bit. The tenth registration took each cell’s cost from the diagonal Fisher on 64 calibration chains. The eleventh measured it on the same chains: each cell alone stored at each width, every other cell exact (768 forwards per batch, 33 minutes on one GH200). Both were scored against uniform formats with the same bytes, the eleventh on 176 MATH-500 chains that no registration had used (Table 8; criteria in Tables S10 and S11). With measured costs the allocation lowers aggregate one-step KL against the uniform format at all three budgets, and at the bytes of INT4 only 6% of sequences get worse, with KL within 1.7× of the exact second order. The diagonal-Fisher allocation matches it where no cell drops to 2 bits; at the bytes of d4h its aggregate (0.3032) misses the registered 0.30 because one sequence holds 44% of its KL.

Where it uses 2-bit cells the diagonal-Fisher allocation fails in the tail: at INT4’s bytes its median was 0.60 of INT4’s on held-out GSM8K, its aggregate 5.18 there and 13.6 on the new chains.

Post hoc interventions localize a major contributor to one cell. Keys of the first loop’s first layer at 2 bits cost 972× their diagonal-Fisher prediction, 99.9% of it in 10 of the 64 chains (the median sequence’s ratio is 1.5); the diagonal Fisher ranks that cell’s upgrade 95th of 96 key cells, measurement ranks it first. The exact second order misses it too: the tenth registration’s worst sequences had KL/JVP of 151–314, so the response is nonlinear, not merely off-diagonal. Storing only its 2-bit key cells (2 of them) at 2 bits reproduces 89–143% of the KL of the tenth registration’s five worst sequences; its 26 2-bit value cells reproduce at most 0.6%. So the registered rule that forbade 2-bit values failed (14.5), and the tenth registration’s post hoc attribution of its tail to value cells was wrong.

The twelfth registration took the cell apart (Table S12). One KV head carries 96% of its cost and the keys of generated tokens 98%; the first token carries 4×10−9, so the registered attention-sink account failed. On GSM8K each of the 9 switching sequences puts over 99% of its KL into one row: after an answer’s two newlines the reference predicts the next few-shot question’s “Q” with probability 0.975–0.988, and with that head’s keys at 2 bits it predicts a third newline. On MATH the flipped rows sit inside the answers, and the cell alone at 2 bits accounts for 80% of the allocation’s KL. The GSM8K aggregates in Table 8 are therefore dominated by one few-shot-format row, whereas the dominant MATH rows fall within answers. Neither aggregate directly measures answer correctness. Raising only that cell to 4 bits (0.2% more bytes) removes the tail: the diagonal-Fisher allocation then reaches 0.85 of INT4’s aggregate on the MATH chains and 0.90 of K4V2’s at 25%, though not the measured-cost allocation’s 0.69 and 0.84.

On Huginn (twentieth registration, one width per four loops, supplementary Table S20) measured block costs again beat uniform formats at every budget (aggregate 0.06–0.58 of theirs); against diagonal-Fisher block costs the result is mixed (1.065 at INT4’s core-cache bytes, median 0.975; 0.13–1.29 at the other budgets). No block cell stands out as Ouro’s does (the largest measured/Fisher ratio is 7.2× the median), the two costs rank the blocks alike (post hoc, ρ=0.987), and one sequence holds 86–88% of the aggregates in which either allocation does badly.

Second Ouro checkpoint. Ouro-2.6B retains the Fisher-value/measured-key split (96.5% / 88.4%). At 31% bytes, measured-cost allocation’s MATH aggregate is 0.596 of uniform INT4’s but 1.134 of Fisher’s, falsifying its registered advantage. Fisher improves on INT4 (0.525); post hoc, both allocator families keep the outlier cell at 4 bits or more. Deadlines left 26/64 measured-calibration and 175/176 MATH chains, meeting minimum gates. These teacher-forced 1.4B-generated chains do not measure 2.6B task accuracy (Appendix G).

On Ouro-1.4B’s calibration chains, the whole allocation’s KL is 0.85 of the sum of isolated-cell costs, which also approximate the diagonal-Fisher allocation’s aggregate there (10.8 predicted, 9.0 measured). At the bytes of uniform INT2 there was nothing to move, because 2 bits is the menu’s floor; the tenth registration missed this.

In free generation. Four registrations generated greedily with each format stored as it would be in a cache (FP32 compute; Tables S13, S14, S15 and S16); exact storage reproduced the teacher-forced chains token for token and did not depend on the batch schedule. Prefill attends exact KV and produces the first output token before the prompt planes are quantized; the format affects subsequent decode steps. On GSM8K the diagonal-Fisher allocation moved 4.5% of answer endings by one extra newline before the next “Q:”, short of the registered 5% (falsified); post hoc, all 9 are among the 19 sequences that switch under teacher forcing, the guarded and measured-cost allocations and INT4 moved none, and a moved ending never changed an answer. On MATH the guard did not improve agreement with exact storage: the guarded and unguarded allocations reproduced 83.0% and 84.8% of the 112 answers exact storage gives (6 against 8 discordant problems; falsified).

A possible explanation is that free generation leaves the teacher-forced path, so the rows that dominate one-step KL need not recur. Answer-change counts alone do not establish this mechanism.

On the 1119 previously unused GSM8K test problems, answer-change counts generally grow as bytes fall; across 10 formats, one-step aggregate KL ranks them with ρ=0.82 (registered). Under strict-match scoring, exact storage scores 60.4% and uniform INT4 59.3% (p=0.12), so the larger loss on the first 200 problems does not replicate (supplementary Tables S16 and S17). At 25% of the bytes the measured-cost allocation does lose accuracy (56.0%, p=5×10−5), more than uniform K4V2 (−1.1 points; 102:65 discordant problems, seen post hoc and then registered and replicated on 1119 unused training problems, 88:60, p=0.013, Table S18). On that replication, the paired accuracy difference is −2.50 points (post hoc 95% interval [−4.63,−0.38]; supplementary Table S22). The training problems were unused by our earlier experiments, but may have appeared in model training. Raising the measured-cost allocation’s 21 2-bit key cells to 4 bits uses 26.37% of BF16 bytes. In the original pooled strict test it recovers part of the gap (150:117, p=0.025), but still scores below K4V2 (106:138, p=0.047; supplementary Table S19). Answer-change counts measure distributional change; accuracy requires paired correctness comparisons. A non-significant comparison with exact storage does not settle whether an allocation outperforms a uniform format.

Answer extraction changes the comparison (post hoc). Rescoring all saved outputs with the frozen task’s flexible-extract rule changes the allocator-minus-K4V2 gap from −3.31 to −0.18 points on the test sample, and from −2.50 to 0.00 on the training sample. The flexible-rule paired 95% intervals are [−2.37,2.01] and [−1.92,1.92]; neither establishes equivalence. Both formats still score below exact under that rule: the allocator’s differences are −5.27 and −3.40 points, respectively (supplementary Table S23). The strict results remain primary, but do not support an extraction-independent accuracy advantage for K4V2 or isolate a reasoning failure. The change in the paired gap itself is 3.13 points on test and 2.50 on training; both descriptive 95% intervals exclude zero (supplementary Table S25).

Direct comparisons across budgets (post hoc). At 31% of BF16 bytes, measured-cost allocation minus uniform INT4 is 0.98 points under strict extraction and 1.70 under flexible extraction (95% interval [0.09,3.31]). At 48%, the differences are −0.27 and 0.00 (Fig. 1c). Fisher allocation at 31% also exceeds uniform INT4 by 1.88 strict and 2.23 flexible points. These unadjusted, retrospective contrasts suggest modest gains at 31%; they do not establish a general ranking by KL or prove that the 31% difference changes with the extraction rule. The full audit includes every complete arm from the four relevant batches, including guarded variants with higher byte budgets (supplementary Tables S24 and S25).

Earlier end-task simulations (H100). In free generation on all 1319 GSM8K test problems Cobbe et al. (2021), residual INT4 formats and direct INT4 with rotation stay within the interval width of BF16 (Table 9); the INT2 formats lose about two points. Residual coding is a capacity format, not a bandwidth one: residual INT4 stores 49% of the BF16 bytes but reads 124% of them per step (Table S1).

An earlier H100 kernel study is summarized separately in supplementary Appendix M; its FP8 throughput measurements do not evaluate the mixed-bit allocator studied here.

Exact release of exited planes. With early exit every plane deeper than a token’s exit holds a copy of its exit plane. Once every position of a page is final, the planes deeper than the page’s deepest exit are byte-identical to it: their table entries can point at its block and their own blocks return to the pool, with no kernel change. Tokens, exit depths and every per-depth KV view are bitwise equal to the copy layout at page sizes 1 to 16 on CPU and in 5 GPU cases on GH200 (CUDA graphs, multi-stream finalize). On GSM8K exit traces with 16-token pages the cache keeps 0.978 of the copy layout’s blocks over whole sequences and 0.913 over decode pages: prompts dominate and mixed exit depths within a page block release. The early-exit policy itself, not the release, costs accuracy (-1.97 pp at threshold 0.5, H100).

9 Negative results and limitations

The diagonal Fisher is not calibrated for aggregate KL, and group-size ratios fail to predict rankings. Huginn’s fixed-point picture does not imply coherent rounding errors or increasing κ2. Residual KV and FP8 without split-KV decoding do not save read bandwidth. Supplementary Appendix I retains the other negative results.

The guard did not establish a MATH task benefit; a full-sample symbolic audit likewise resolves no allocator advantage (Appendix L). The 25% strict-score loss is extraction-sensitive; the 31% gains are retrospective, unadjusted and independently unconfirmed. Neither extraction rule adjudicates reasoning, and the training-split replication is not known to be contamination-free.

Evidence covers two primary checkpoints and a partial second-Ouro diagnostic, fixed mathematics prompts and greedy decoding with length caps. Prompt robustness, sampling and matched non-looped controls are untested. Huginn uses a deterministic token-dependent initial state; its four-loop allocation blocks differ from Ouro’s per-loop cells, confounding model-family comparisons.

Isolated-cell costs need not add jointly, and greedy allocation has no global-optimality guarantee. Intervals omit recalibration variability. Ouro’s calibration required 768 forwards per batch and 33 minutes on one GH200; cost amortization and stability under prompt-distribution shifts are unmeasured.

Nominal budgets include scales and offsets but omit packing, alignment, format indices and workspaces. The FP32 simulation uses exact-KV prefill. A separate L40S physical-cache pilot uses less retained cache but fails its full-model reader gate; its batch-one timings cannot establish a quality-qualified speedup (Appendix P). Capacity and concurrency remain untested. FlashLoop’s different packer fails a strict CPU bitwise check in 16 of 20 synthetic cases (Appendix O); this is not a test of our allocator.

10 Related work

Looped and recurrent-depth models include Universal Transformers Dehghani et al. (2018), Huginn Geiping et al. (2025), Ouro Zhu et al. (2025) and Hyperloop Transformers Zeitoun et al. (2026). Systems work batches loop depths continuously Schwethelm et al. (2026), aliases KV across exit depths Mishra et al. (2026), drafts from shallow loops Cho et al. (2026); Ha & Kim (2026); Li et al. (2026), contrasts early and late readouts Liu et al. (2026), and compresses cross-loop KV Neill & Reid (2026); Yang & Liu (2026). Quantization of looped models has been studied for weights and activations Fang et al. (2026); Li (2026) and for residual KV Kim et al. (2026). General KV quantizers Liu et al. (2024); Hooper et al. (2024) and rotations Ashkboos et al. (2024) motivate our formats; second-order sensitivity is standard in weight quantization Dong et al. (2019); Nagel et al. (2020); Frantar et al. (2022), and paged KV management follows Kwon et al. (2023). Our theory tests borrow tail-index estimation Hill (1975), the error analysis of stochastic rounding Gupta et al. (2015), and the fixed-point view of iterated depth from equilibrium models Bai et al. (2019).

11 Conclusion

Across the studied checkpoints, values dominate Fisher mass while keys dominate measured KL. Second-order prediction tracks typical sequences, but aggregates and rare rows require direct measurement. Shared-weight amplification also depends on error direction; at R=32 the local ratio ranges from 1.65 to 4.09.

Measured costs expose a nonlinear key failure on Ouro-1.4B, yet lose to Fisher on the second checkpoint. Task contrasts depend on budget and scoring. KL remains a diagnostic; task and serving benefits require separate validation.

Appendix C First batch: bytes, criteria and the dominant sequence

Bytes stored and bytes read. Formats differ in what they store and in what one decode step reads. Loop ℓ reads plane ℓ. A residual format that codes planes 1..R−1 against the final plane must read the reference and the residual for each of those loops; the two reads are a full core apart and do not share cache lines. Table S1 shows the consequence: the residual INT4 format of the earlier study stores 49% of the BF16 bytes but reads 124% of them per step. Residual coding is a capacity and transfer format, not a bandwidth format.

Pre-registered outcome. Table S2 lists the criteria. The aggregate measured/JVP ratio falls in [0.8,1.25] for only 7 of 21 formats, the log–log slope of measured KL on the diagonal prediction is 1.24, and the group-size ratios are not predicted. Additivity, the rounding-temperature test and the floors pass. For the formats in the linear band, KL scales as ϵ2 under Δ→ϵ​Δ: KL⁡(ϵ)/(ϵ2​KL​(1)) at ϵ=14,12,2 is 1.02, 1.00, 1.05 for d4h-all and 1.03, 1.02, 0.99 for FP8; for residual INT2 (r2h) it is 0.25, 0.23, 2.59.

Why the aggregate fails (post hoc, CPU). We recomputed the sequence with the largest discrepancy for d4h-all on CPU with the same weights; its measured KL matches the GH200 value to a ratio of 1.002. There the JVP predicts 11.5 times the measured KL. Figure 3 shows that the JVP is the correct small-perturbation limit: KL⁡(ϵ)/ϵ2 rises from 0.95 to 1.93 to 7.28 times KL⁡(1) at ϵ=14,116,164, and central differences give 11.1 at step 1256 but 0.99 at step 116. One of its 95 rows carries 92.6% of the second-order term. In that row the model is confident (top probability 0.9998) and the logit tangent reaches about 152 for tail tokens. Linearizing the network but keeping the output softmax exact makes the prediction worse, by 828–7322 times on that sequence for the four rotated or FP8 formats, so the saturation is inside the network: the root-mean-square logit change per unit perturbation falls from 4.07 at step 1256 to 1.45 at step 116. Section 5 (T7) localizes it on five such sequences and confirms it, re-registered, on 12 new ones: in all 19 scored cases loops 1 and 2 hold at least 99.8% of the excess. The single dominant row and the agreement of differences with the JVP were shown on one sequence, and the tangent-logit comparison on 3.

Rounding and group size. Stochastic rounding on the INT4 grid measures 0.85 of the prediction built from the expected squared error, and is 1.72 times worse than round-to-nearest against a predicted 2.00 (P4). Group-size effects (P3) are not predicted: the comparisons pass through the same outlier sequences, which change the ranking.

Appendix D Theory tests in full

Design. After the first batch we wrote down seven predictions. Each names a source theory, a numerical prediction and a falsification condition, and all were frozen before the second set of GPU jobs. They are tested on data not used to form them: 136 held-out GSM8K chains for Ouro (14,474 scored rows, 24 formats including three new group-size arms), 24 MATH-500 chains (10,786 rows) and Huginn-0125. Table 3 lists predictions, measurements and verdicts. Its last column is post hoc and never changes a verdict. A third pre-registration, at the end of this section, re-tests the open Huginn points and T7 on new data (Table S3).

Huginn. Huginn-0125 runs a prelude of 2 layers once, iterates a core block of 4 layers R=32 times from a random initial state, and finishes with a coda of 2 layers; attention has 55 heads of dimension 96 Geiping et al. (2025). We quantize the R×4 core planes and keep prelude and coda KV exact. The random initial state is replaced by a deterministic draw seeded by the token ids, so every pass over the same tokens sees the same state. E1 uses Huginn’s own greedy chains from the third batch: 80 GSM8K prompts generated with a causal state (position t seeded by tokens 0..t), capped at 224 tokens (74 stopped, 6 hit the cap, median 87 tokens). Teacher forcing reproduced every generated token (0 mismatches). E1 runs on 64 of them (6,674 rows, 8 formats). The second batch first tested T3 and T4 on 16 Ouro chains decoded to text and re-encoded for Huginn (1,529 rows), with a state seeded by the whole padded row; we report those verdicts as registered. E2 uses 8 re-encoded chains (787 rows) in both batches, so that κ is measured on identical inputs at R∈{4,8,16,32}.

T1: the aggregate is not self-averaging. Let the per-sequence excess rs=Qs/KLs of second order over measured KL have a power-law tail, P⁡(r>x)∼x−α. For α<1 the mean does not exist and ∑sQs is dominated by its largest term; for 1<α<2 the mean exists but the variance does not, and the aggregate converges slower than N−1/2. On the held-out chains the light-tailed formats aggregate inside [0.8,1.25] (d4-all 0.99, FP8 0.89, BF16 0.94) and the heavy-tailed ones outside it (r4h-g128 0.79, r2h 1.55), while all medians fall inside. Two numbers miss: r4h-g128 deviates by 0.21 instead of at least 0.5, and its Hill index Hill (1975) is 1.27 instead of below 1. Its largest sequence holds 6% of the second-order sum, against 91% in the first batch. The Hill indices keep their order (r2h 0.94, r4h-g128 1.27, d4h-all 1.55, FP8 2.06, d4-all 2.45). The heavy tail is real, but on the larger sample it sits at 1<α<2.

T2: group size as a screening length; rotation as Gaussianization. Per-group scaling lets every group of g elements set its own range, much as a screening length sets the range of an interaction. On a uniform grid the error is Δ2∝rangeg2. The range of g samples grows like 2​ln⁡g for a Gaussian tail and like g1/α for a power-law tail, so the two tails predict different group-size laws. A Hadamard rotation mixes coordinates and makes each close to Gaussian Ashkboos et al. (2024). The predictions came from exact CPU quantization of planes from 6 further chains. Unrotated keys have kurtosis 9.5 (values 6.4), rotated ones 3.1 (3.7). The unrotated key error grows by 4.51 from g=16 to g=128, which corresponds to α≈2.8. Table 4 compares median measured KL ratios with those error ratios. All five fall in their bands on both distributions, and the unrotated ratio stays above the Gaussian law’s 2.80. At these finite group sizes the rotated ratios, like the exact error ratios they track, lie below that asymptotic law. What T2 confirms is that measured KL follows exact error ratios in both branches and that the unrotated branch is not Gaussian; that rotation makes coordinates Gaussian rests on the kurtosis. Unlike P3 of the first batch, which compared aggregate ratios through the diagonal Fisher, T2 uses medians, which the outlier sequences do not move.

T3: quenched and annealed rounding. For a fixed input, round-to-nearest (RN) gives a fixed, quenched error; stochastic rounding (SR) gives an annealed one Gupta et al. (2015). With a uniform fractional part f, RN has mean square error E⁡[min⁡(f,1−f)2]=112 of a step squared and SR has E⁡[f⁡(1−f)]=16, a factor of 2. SR measures 1.95 times RN on held-out GSM8K, 2.06 on MATH-500 and 1.76 on Huginn. The SR measurement divided by the prediction from the expected squared error is 1.05, 1.09 and 1.04. On Huginn’s own chains the two ratios replicate at 1.68 and 0.96.

T6: distribution independence. On MATH-500, values carry 95.7% of the diagonal Fisher mass and the final plane 63.6%, against 94.6% and 72.8% on held-out GSM8K. The set of formats whose median lies in the band differs from the first batch’s by 1 format.

T7: where the saturation sits. On the 5 most discrepant sequences and two formats, we restricted Δ to one layer (all loops) or to one (loop, layer) cell, and recorded the JVP and the KL at ϵ=1 and 116. Layers and loops are numbered from 1. The pre-registered metric, the top three layers’ share of the whole-sequence JVP, is ill-posed: restricted JVPs omit cross-layer terms and do not add, and the share ranges from 0.04 to 2.56. It fails, and the falsification condition does not occur (at most 6 layers carry 5% of the excess; the threshold was 8). Post hoc, we use each layer’s share of the excess JVP−KL instead. In 4 of 10 cases one layer holds at least half of it. For r4h-g128 on the sequence where the JVP exceeds the KL 43-fold, layer 6 holds 92%. Layer 6 is the top layer in 4 cases, and the largest cell lies in loop 1 or 2 in all 10. The third batch re-registered T7 with this excess share and tested it on 12 new sequences selected by a fixed rule from the held-out chains, restricting Δ to one layer or to one loop. Of 24 cases, 19 have JVP/KL of at least 1.5 and are scored. The median share of the top three layers is 0.76 (range 0.56–0.92), loops 1 and 2 hold at least 99.8% of the excess in every scored case, and at most 7 layers carry 5% of it. All three criteria pass. The top layer varies: layer 6 leads in only 3 of 19 cases. The saturation sits in a few layers of the first two loops, but not in one fixed layer.

Appendix E Huginn: separation, the switching sequence and spectra

T4: on Huginn’s fixed point, coherent rounding errors add only weakly. Huginn is trained so that its latent state approaches a fixed point over the loops, as in equilibrium models Bai et al. (2019). Adjacent late planes then nearly coincide, so RN should give them nearly equal errors. The cross-plane Fisher terms would then add, and the diagonal prediction would underestimate RN but not SR. The planes do converge: on Huginn’s own chains the relative change of keys between loops falls monotonically from 0.54 to 0.014, and is 0.044 between loops 16 and 17. The predicted underestimate is small. On the re-encoded chains of the second batch the median measured/diagonal ratio is 1.14 for RN and 1.04 for SR, a ratio of 1.13, below the falsification threshold 1.2. On the own chains it is 1.12 against 0.96, a ratio of 1.21.

The third batch measured the two candidate reasons directly, on 10 own chains with one sequence at a time. In the Fisher metric ⟨a,b⟩=∑tCovpt​(a,b), with Jℓ the logit tangent of plane ℓ and Δℓ its storage error, it compares three normalized quantities for adjacent planes. The first is the correlation of the two errors seen through one Jacobian, ρJ=⟨Jℓ+1​Δℓ,Jℓ+1​Δℓ+1⟩. The second is the alignment of the two Jacobians on one error, A=⟨Jℓ​Δℓ,Jℓ+1​Δℓ⟩. The third is the realized coherence X=⟨Jℓ​Δℓ,Jℓ+1​Δℓ+1⟩. Over the last eight planes the RN errors are correlated (ρJ=0.87, element cosine 0.76), while SR, the negative control, is not (0.02). The Jacobians are nearly orthogonal (A=0.13), so the realized coherence is only X=0.09. Cross-plane terms make up 13.9% of the RN second-order term and 2.5% of the SR term; adjacent pairs account for 65% of the RN cross term. This is the pre-registered class (Table S3). Post hoc, the Jacobians alternate with parity in the earlier loops. For loops 9–24 the alignment is −0.38 at distance 1 and +0.31 at distance 2 (per pair down to −0.80 and up to +0.73), and the realized coherence there is negative (−0.28). One reading is a linearized loop map with an eigenvalue near −1 in the middle loops, which fades in the late ones. The fourth batch measured dominant Ritz values of the loop map (Table S4, C): for three ordinary sequences they are mostly real and negative in the middle loops (10/15 cells, −1.10 to −0.82), but so are the late ones, so the mode exists and is not confined to the middle loops. With 72 steps every cell converges (32 of 32) and the picture is unchanged: negative dominant values in 10/20 middle cells and 8/12 late ones (Table S5, C).

The final plane holds 40.8% of the Fisher mass on the own chains (35.6% on the re-encoded ones), more than the predicted ceiling of 30% but far below Ouro’s 67%. The last five planes hold 89%, and planes 1–20 together 2.0%. Values carry 58% of the mass, against 94% on Ouro.

Outside the predictions, typical linear response is good on Huginn. The median measured/JVP ratio is 0.97–1.01 for 7 of 8 formats and 1.26 for d2h. The aggregate behaves differently on the two chain sets. On the re-encoded chains it falls below the JVP (d4-all 0.66, r2h 0.33), as on Ouro. On the own chains it rises above it (1.58 and 4.12), and one sequence of 85 tokens accounts for that. There, KL is 31 and 41 times the JVP and carries 36% and 73% of the two formats’ KL. Its scale sweep KL⁡(ϵ)/(ϵ2​JVP) reads 1.11, 2.26, 31 and 9.08 at ϵ=14,12,1,2: doubling the perturbation from 12 to 1 multiplies the KL by 54. A response switches on near the quantization scale, the opposite of the saturation seen on Ouro. The fourth batch located it (Table S4, A). One of the sequence’s 85 rows carries 99.0% of the excess (KL 6.55 of 6.78; the other rows sum to 0.22, against a JVP of 0.221 for the whole sequence), and its argmax flips between ϵ=12 and 34. The row is not a near tie: its reference margin is 2.55 logits, the 38th percentile of the sequence (median 3.36). Restricting the error to one layer puts all of it in the last core layer (KL 5.95 against a JVP of 0.113; the other three layers are linear within 0.03); restricting it to one loop puts it in loop 8 (KL 1.83, JVP 0.0021), while the single-loop errors of loops 25–32, where the Fisher mass sits, stay linear (KL/JVP 0.84–1.05). Residual INT2 flips the same row at ϵ=1.5 with an error 27 times smaller. The sequence’s loop map is the only one of 4 measured whose dominant Ritz value in loops 10–22 is real, positive and above one (1.04–1.23, 4 of 5 cells converged; −0.95 at loops 30–32): an error injected in loop 8 grows about 7-fold before the map contracts again, which is how a middle-loop error in one layer flips a row with a margin of 2.55 logits. On all 64 own chains (Table S5, A; 40 Arnoldi steps, 177 of 192 middle-loop cells converged), 9 chains (14%) have such an expanding middle-loop mode, and the switching sequence ranks 2 by its largest real part (1.23; the largest is 1.25). Expansion is necessary for the switch but does not produce one: the expanding chains’ median KL/JVP is 1.01 against 1.01 for the others, and the Spearman correlation between the largest real part and log KL/JVP is 0.21 (−0.08 for the modulus). Without the three largest excesses the aggregates are 1.02 and 1.07, and the median sweep over all sequences stays within 1.00–1.06. Residual coding gains much more than on Ouro: per row, residual INT2 gives 7.0×10−5 and direct INT2 2.4×10−2, a factor of 346 against 10 on Ouro, and residual INT4 (7.6×10−7) comes close to BF16 (6.5×10−7). Converged planes leave small residuals.

Appendix F Weight sharing on Huginn

T5: κ⁡(R) and the correlation length of loop gradients. Write Cℓ​ℓ′=∑iE⁡[gℓ,i​gℓ′,i]​Δ​Wi2, so that κ=𝟏⊤​C​𝟏/tr​C. If the correlation ρ of loop gradients decays with loop distance over a correlation length ξ, then κ⁡(R)≈1+2​∑k≥1(1−k/R)​ρ​(k) grows with R and saturates once R≫ξ. If converged late loops had nearly identical gradients, ρ→1 and κ would grow linearly in R. With 8 Fisher draws per batch, the second batch found κ growing 3.44-fold from R=4 to R=32, formats agreeing within 1.8%, and the Fisher-free ratio agreeing with κ where it was measured. The predicted structure did not hold: the correlation rose in 168 of 465 steps along the diagonal, and pairs of late loops (25–32) correlated at 0.068, against 0.26 for early ones (1–8).

The third batch repeated R=4 and R=32 on the same batches with 32 draws. The KL of every batch and format matched the second batch bitwise (36 values), so only the sampled labels of the Fisher differ. Table 6 merges the two batches. With 32 draws, κ⁡(32)=2.68±0.21 (jackknife over draws), not 3.66. Four disjoint subsets of 8 draws give 2.04, 2.92, 2.46, 3.25: 8-draw estimates scatter widely, and the second batch’s value lies above all four, so sampling is the likely cause but not a proven one. The growth remains, at 2.53-fold, with formats within 1.6%.

The size of κ⁡(32) also depends on the estimator. κ is a ratio of diagonal Fisher terms, and at R=32 the diagonal shared prediction is only 0.56 of the exact second order (per batch 0.39–0.80; 1.04 at R=4). Replacing the numerator by the exact second order, JVPall/12​tr​C, gives 1.02, 1.37, 1.69 and 4.79 at R=4,8,16,32. Both readings grow; their values at R=32 differ by almost a factor of two. INT8 is still linear at R=32 (measured/JVP 1.03) and gives κ=2.70, so the growth is a property of the gradients, not of saturation. INT4 and FP8 leave the linear regime there (0.59 and 0.69): the INT4 scale sweep KL⁡(ϵ)/(ϵ2​JVP) reads 1.12, 0.82 and 0.29 at ϵ=14,12,2, against 0.87–1.00 at every ϵ for R≤16. Per batch, κ⁡(32) ranges from 1.65 to 4.48, and all 6 batches exceed κ⁡(16), itself a 8-draw estimate. The count-sketch estimate of C gives 2.73 against the exact 2.68.

The fourth batch measured the exact second order at R=32 on the same batches (Table S4, B; the KL of every batch and format equals the third batch’s bitwise, 12 values). κ2=JVPall/∑ℓJVPℓ is 4.09 for INT4 and 1.65 for INT8, where the diagonal κ is 2.68 and 2.70. The registered expectation that κ is a property of the gradients alone, and so the same for both formats within 25%, fails: the local second-order coherence depends on the direction of the weight error, which the diagonal Fisher averages out. INT8 is in the linear regime (KLall/JVPall=1.03, single loops 0.98), and its measured coherence KLall/∑ℓKLℓ=1.74 agrees with 1.65; for it the diagonal Fisher overstates the shared term (1.83 of the exact) and the single-loop terms (1.12). For INT4 the whole error saturates (0.59) while its single-loop errors in loops 6–16 are super-quadratic (KL/JVP 0.8–4.6 per loop, against 0.94–1.18 in loops 25–32 and 0.45–1.20 for INT8 everywhere), the same middle-loop amplification as the switch above; its diagonal shared term is 0.56 of the exact one, so the 0.56 above is an INT4 figure. Per batch, κ2 ranges from 2.2 to 8.0 (INT4) and 0.98 to 3.3 (INT8). The measured coherence at R=32 is 1.81 for INT4 and 1.74 for INT8, close to each other and well below the INT4 κ2; Table 6 lists it. On 8 of Huginn’s own chains with the causal state (Table S4, D), the diagonal κ⁡(32) is 2.43±0.14 (32 draws, jackknife 5.6%; per batch 1.96–2.79), 1.0σ from the re-encoded chains’ value, with κ⁡(4)=1.079 and formats within 1.1%.

The fifth batch asked which property of the direction matters (Table S5, B; INT4 KL and JVP bitwise equal to the fourth batch’s). The registered hypothesis was that coherence is carried by the systematic part of the error, the part that moves the fixed point the same way in every loop: zero-mean stochastic rounding on the INT4 grid should then match INT8, pure shrinkage (Δ=−10−3​W) should exceed INT4, and the group-mean bias of the INT4 error should carry most of it. All three directions give κ2 between 2.21 and 2.44 (SR 2.44, bias 2.37, shrinkage 2.21), between INT8’s 1.65 and INT4’s 4.09, and the INT4 error is no more aligned with W than INT8’s (cosine 0.0026 against −0.0002). The direction dependence is real but not along this axis. Per batch, κ2 spans 0.56–7.28 for SR and 0.87–5.64 for shrinkage, more than the spread between directions: on eight chains a direction’s κ2 is set by a few batches, and the INT4/INT8 difference is a property of these chains, not a constant.

The sixth batch tested the obvious reading of that chain dependence and was falsified (Table S6). Per chain, the four INT4-sized directions of the fourth and fifth batches rank the same eight re-encoded chains alike (Spearman 0.76–0.93), so we registered that κ2 rises with the largest real part of a chain’s middle-loop dominant Ritz value: an expanding map should align every loop’s error along one direction. On 16 own chains, the eight with the most expanding middle-loop modes (1.02–1.25) against the eight with the most negative (−1.12 to −1.03, period-two modes of modulus just above one), the correlation is −0.18 for INT4 and −0.36 for shrinkage, and the period-two chains are the more coherent ones: median κ2 4.34 against 2.64 for INT4 (1.6×) and 2.85 against 0.97 for shrinkage (2.9×; shrinkage is linear on every chain, measured/JVP 1.01–1.58). The chain dependence itself replicated out of sample: INT4 and shrinkage rank the 16 new chains alike (Spearman 0.84). A post hoc reading that fits both this ranking and the parity alternation of Figure 4: along a period-two mode the state alternates, so the weight error’s effect on it alternates too, and the two alternations cancel in propagation, so the alternating component of the error accumulates across loops; a positive expanding mode has no such phase lock. The seventh pre-registration tested its signature, the lag structure of pairwise loop cross terms cℓ​m=12​(JVPℓ​m−JVPℓ−JVPm) in the middle loops, on four chains of each group (Table S7). Even lags exceed the neighbouring odd ones in 3 of the four period-two chains and in 3 of the four expanding ones, and the even-lag means differ by 1.23×, not the registered 2×; the purest alternation (odd lags down to −0.89, even lags at least 0.80) belongs to an expanding chain whose κ2 is 0.57, below one. The measured pairs carry only 6–19% of the total cross term JVPall−∑ℓJVPℓ, because 43–87% of the single-loop second order sits in loops 25–32. Writing κ=1+ρeff​(Neff−1) with Neff=(∑ℓJVPℓ1/2)2/∑ℓJVPℓ, the two groups overlap in Neff and differ in ρeff (0.11–0.18 against −0.02–0.07 for shrinkage), far below the middle-loop short-lag correlations: the difference lies in late and long-range pairs, which this batch did not measure.

The eighth batch measured all of it (Table S8). Because the JVP is a quadratic form in the coefficients aℓ of the tangent ∑ℓaℓ​Δℓ, four block JVPs (loops 1–8, 9–24, 25–28, 29–32), the six unions of two blocks, and one JVP with signs (−1)ℓ split the cross term exactly: into within- and between-block parts, and into the sums E and O over even and odd lags, with JVPall−∑ℓJVPℓ=2​(E+O). On the sixth batch’s 16 chains every whole JVP matched bitwise and the decomposition closed to 2×10−6 of JVPall. For shrinkage the registered predictions held: late-involving pairs carry 0.63 of the chain-to-chain covariance of κ−1 and a median 0.59 of the cross term, and κ rises with the odd-lag balance O/(|E|+|O|) (Spearman 0.88). Two post hoc checks qualify both. Under equal correlation of all pairs the late share would be 0.80, so late pairs are under-correlated for their mass (0.75×) and the large share only follows the single-loop mass; pairs within loops 9–24 hold 0.31 of the cross term against 0.14 under equal correlation, 2.2× enriched, as the third batch’s middle-block share suggested. The odd-lag correlation is partly algebraic, since κ<1 with E>0 forces the balance below −12; on the 10 chains with κ>1.05 it is 0.64. Since κ−1=2​E/∑ℓJVPℓ+2​O/∑ℓJVPℓ, the variance of κ−1 splits exactly into covariance shares of the two lag classes, free of that coupling: odd lags carry 0.87 and even lags 0.13 (INT4: odd 0.56; post hoc). In each of the 5 chains with κ<1 a negative odd-lag sum outweighs the even-lag sum, by a narrow margin where both are large (2.21 and −2.42 of ∑ℓJVPℓ for the chain of the seventh batch’s purest alternation): parity alternation can be strong across all loop pairs, and it cancels coherence rather than building it. This is a property of the cross terms, not of the loop map’s spectrum: the sixth batch’s period-two chains, with negative dominant Ritz values, have positive odd-lag sums (median 0.11, against −0.18 for the expanding chains; Spearman between the largest middle-loop real part and O/∑ℓJVPℓ is −0.33). For INT4, recorded but not scored, the pattern is reversed: pairs within loops 9–24 carry 0.53 of the covariance and 0.55 of the cross term (3.5× their equal-correlation share), late-involving pairs 0.35. Which chains are coherent is shared across error directions; where the coherence sits is not.

With 32 draws the off-diagonal part κ−1=1.72 splits by loop blocks as follows: middle loops (9–24) among themselves 0.88 (51%), early with middle 0.30, middle with late 0.22, late among themselves 0.23, early among themselves 0.08, early with late 0.00. The late loops hold 69% of the diagonal Fisher, but adjacent late loops correlate at only 0.04–0.22, and late pairs correlate at 0.061 against 0.19 for early ones. The coherence comes from the middle loops, and that is the same finding as T4: near the fixed point, loops neither add KV rounding errors coherently nor align their weight gradients. Post hoc, the correlation alternates with the parity of the loop distance (Figure 4). Mean correlations at distances 1 to 6 are 0.23, 0.43, 0.08, 0.29, 0.05, 0.22; in the middle loops distance 1 averages 0.25 and distance 2 0.62, and ρ⁡(ℓ,ℓ+2) reaches 0.78 where ρ⁡(ℓ,ℓ+1) peaks at 0.44. The KV Jacobians of T4 show the same parity, measured independently with exact JVPs.

Appendix I Negative results

  • Mature-value drafting does not transfer to Ouro (H100). Reading final-loop values in a depth-2 self-speculative draft lowers draft–target agreement from 0.966 to 0.438 on GSM8K. Values converge across loops more slowly than keys (mean cosine to the final loop at loop 1: 0.83 for keys, 0.61 for values) Li et al. (2026).
  • Residual KV reads more bytes than BF16 (Table S1).
  • FP8 KV without a split-KV kernel is not faster at equal concurrency (§8).
  • The diagonal Fisher is not a calibrated aggregate predictor (P1d, slope 1.24), nor are group-size ratios (P3).
  • No amplification by weight sharing between R=1 and R=4 on Ouro (§6). On Huginn, INT4 and FP8 weight errors leave the linear regime at R=32 while INT8 does not; that observation is post hoc and is not the pre-registered test.
  • A fixed point does not make errors add coherently (T4a, T5c). Huginn’s converged late planes have strongly correlated rounding errors, but nearly orthogonal output Jacobians, and its late loops do not align their weight gradients.
  • The second batch overstated κ⁡(32) (3.66 with 8 Fisher draws, against 2.68±0.21 with 32; K-d).
  • The local second-order coherence depends on the format (B1, B2): 4.09 for INT4 and 1.65 for INT8 at R=32, where the diagonal κ gives 2.68 for both. The switching sequence is neither a near tie nor a late-plane effect (A2, A4).
  • Neither an expanding loop-map mode nor the systematic part of a weight error explains the exceptions (fifth batch): 14% of the own chains have an expanding middle-loop mode and one of them switches; stochastic rounding, group-mean bias and pure shrinkage all give κ2 of 2.21–2.44.
  • Coherence does not rise with an expanding loop map (sixth batch, falsified): chains with period-two middle-loop modes are 1.6–2.9× more coherent than chains with expanding ones.
  • Parity alternation of loop cross terms does not carry the coherence (seventh batch): it appears in both groups, and its purest case cancels to κ2=0.57.
  • The aggregate’s tail is not mean-divergent (T1). The heavy-tailed formats keep a tail index between 1 and 2 on held-out chains, not below 1.
  • The pre-registered localization metric is ill-posed (T7): restricted JVPs omit cross terms.
  • Measured block costs do not beat diagonal-Fisher block costs on Huginn (twentieth registration, H1a and H1c): 1.065 of the Fisher allocation’s aggregate at INT4’s bytes and 0.13–1.29 at the other budgets; no block cell’s measured/Fisher cost ratio exceeds 30 times the median (registered question O1, Table S20).
  • Measured cell costs do not beat diagonal-Fisher cell costs on a second Ouro checkpoint (twenty-first registration, T3 falsified): on Ouro-2.6B the measured-cost allocation’s aggregate KL at INT4’s bytes is 1.134 of the Fisher allocation’s, and the Fisher allocation does not fail in the tail (F1, 0.53 of uniform INT4’s). An outlier cell exists (O1, 125× the median ratio), but neither allocator family stores it at 2 bits (Table S21).

Appendix K Answer-extraction sensitivity audit

Scope and provenance. This post hoc audit asks whether the 25%-budget comparison survives a change of answer extraction. It uses two filters already present in the frozen GSM8K-CoT task configuration: strict-match, which requires the phrase “The answer is” followed by a numeric match, and flexible-extract, which selects the last numeric match. Both then apply the same saved exact-match normalization against the reference answer. The strict results remain primary. The analysis plan was saved before computing flexible scores, after strict parser failures were known; it is not a prospective registration and adds no criterion to the ledger.

The test sample contains 1119 problems: exact outputs are from historical v17 and the two quantized arms from v18, with matching input and tokenizer hashes. All training-sample outputs are from v19, the eighteenth registration. We rechecked raw-file hashes, completeness, unique IDs and input/output ID equality, and reproduced every saved strict answer, correctness and parse-failure flag across 6714 generations. No capped, unparseable or incorrect output was discarded; no model was rerun. An independent CPU rescore of the original files on Arrhenius reproduced the complete indicator-table checksum. The upstream lm-evaluation-harness v0.4.9 RegexFilter implementation also matched all 13,428 extractions across the two rules. This validates extraction on the saved text, not the full inference harness.

The relative gap depends on extraction. Under flexible extraction, the test difference is only two correct answers (816 versus 818), and the training counts are equal (883 each). The intervals still allow losses of about 2 points and gains of similar size, so these results do not establish equivalence. Both formats remain below exact under flexible extraction: on test, allocation-minus-exact is −5.27 points ([−7.50,−3.04]) and K4V2-minus-exact is −5.09 ([−7.32,−2.86]); on training, both differences are −3.40 points, with intervals [−5.32,−1.47] for the allocation and [−5.27,−1.52] for K4V2.

Parseability and limitations. Strict extraction fails on 266/227/256 test outputs and 207/175/214 training outputs (exact/K4V2/allocation); flexible extraction fails on 0/0/1 and 0/0/0, respectively. The released indicators retain each output’s parseability, correctness under both rules and stopping reason. They show that many strict failures yield the reference number under flexible extraction, but a last-number heuristic can also select an intermediate or unrelated number and can overturn a correct strict answer. Thus this audit does not prove that formatting causes the entire gap, or adjudicate the reasoning. The training sample is unused by earlier experimental batches, not guaranteed absent from model training. We do not pool the splits. The supported conclusion at 25% is that the strict-score advantage of K4V2 over the measured-cost allocation is extraction-sensitive.

Appendix N Interpretation limits

Generation protocol and task measurements. The Ouro mixed-bit generator attends exact KV throughout prefill and computes the first output token before quantizing the stored prompt planes. Subsequent steps attend the stored, transformed KV of previous tokens together with the current token’s fresh KV. The free-generation results therefore test decode-time storage perturbations, not a pipeline that also quantizes prefill attention. Teacher-forced one-step KL and free-generation accuracy also follow different token trajectories. A high-KL delimiter row need not recur in free generation, and a high-KL row within a MATH answer does not by itself show that the answer is wrong. Ratios of summed KL weight chains by their reference KL, so a tail-dominated aggregate can differ from an unweighted per-chain comparison; neither directly measures task correctness.

Both task evaluations use fixed few-shot templates, greedy decoding, stop strings and generation caps. The MATH pilot’s answer-agreement analysis conditions on the 112 of 200 problems for which exact storage yields a parsed answer; it does not describe agreement on all problems. Matching exact is not an accuracy oracle: exact storage’s normalized-string accuracy is 43.0%. The full-sample symbolic audit in Appendix L raises exact accuracy but does not resolve a direct allocator advantage on this pilot. The guarded and unguarded allocations agree with exact on 93 and 95 of those 112 problems, respectively (6:8 discordant pairs), so the failed improvement test does not establish equivalence or identical answers. The GSM8K extraction audit rescores the same saved outputs under two rules, without adjudicating reasoning or supplying an independent generation sample. Unused training-split questions need not be absent from model pretraining. These experiments do not measure robustness to prompt changes, alternative decoding policies or other task domains.

Allocation uncertainty and transfer. Isolated-cell calibration measures each perturbation with the other cells exact. The observed agreement with joint costs on the calibration sample does not guarantee additivity for other allocations or prompts. The greedy search is not compared with a global optimum. Paired task intervals condition on the checkpoint, prompts and selected format; they omit variability from resampling calibration chains and choosing a new allocation, as well as multiplicity from the exploratory comparisons. Guarded formats can spend more bytes than their references, so those contrasts do not isolate the benefit of a guard at fixed budget. Ouro allocates per loop, layer and K/V cell, whereas Huginn groups four adjacent loops; changes in outlier strength or allocation gains can reflect this granularity as well as model differences. The later second-Ouro test remains conditional on 1.4B-generated chains and incomplete measured calibration. One Huginn checkpoint and the absence of a matched non-looped control also limit architecture-level attribution. Huginn’s shared-weight decomposition covers two error directions and 16 plus 12+12 chains, with no expanding chain in the new samples. Few Fisher draws overstate κ⁡(32) (3.66 at 8 draws), and odd-lag terms explain about half, rather than most, of the chain-to-chain variation out of sample. H100 and GH200 measurements are linked only by the reported reproduction checks.

Calibration and implementation cost. Ouro’s measured-cost calibration uses 64 chains and 768 forwards per batch, taking 33 minutes on one GH200. The study does not measure how many requests would amortize that cost, how often a changed prompt distribution requires recalibration, or whether the allocated widths remain stable across calibration samples. Huginn’s budgets cover core KV only, with prelude and coda KV left exact; they are not whole-cache compression fractions. Nominal storage includes group scales and offsets but does not measure format-index storage, packing alignment or temporary workspace. Dense FP32 computation isolates storage error without testing its interaction with lower-precision arithmetic. The earlier FP8 kernel measurements concern a different implementation; they cannot supply packed mixed-bit throughput, latency, capacity or concurrency measurements.

Fair serving comparisons. A shared attention reader can isolate cache-format effects but does not establish competitiveness with an optimized BF16 serving implementation. A direct comparison requires the same checkpoint, hardware, context, output length, batch and loop count, with compute precision and kernel differences stated explicitly. Prefill and decode must be timed separately after warmup; compile time, retained cache storage and peak allocator memory have different meanings. Methods that combine token sparsity and cache quantization also change the work performed; switching off token selection need not restore the same dense kernel. Component ablations alone therefore cannot attribute a speed difference to quantization. The separate L40S pilot below supplies single-request implementation timings, but its reader fails the model-level numerical gate and it does not measure an accuracy–throughput tradeoff. Concurrent serving and maximum feasible batch capacity remain unresolved.

This separately registered pilot uses the same pinned Ouro-1.4B checkpoint and common BF16 frontend as the preceding component checks, on one L40S while other GPUs on the host run other workloads.
